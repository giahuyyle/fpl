# Local Premier League club crests

Files in this directory are generated by `npm run sync:assets` and are ignored
by Git. The sync stores the current season's 50px club crest PNGs locally and
writes a manifest with their source URLs, checksums, byte sizes, and sync time.

When the manifest belongs to an older season, the next sync refreshes every
crest even if the club code and filename have not changed.

These club marks are third-party assets. Before using or distributing them,
confirm that your use complies with the Premier League's current terms and any
applicable permissions.

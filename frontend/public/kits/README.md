# Local FPL kit assets

Season folders in this directory are generated by `npm run sync:kits` and are
ignored by Git. The squad pitch falls back to its generic player image when an
asset has not been synced or cannot be loaded.

The sync reads team codes and gameweek dates from the repository's saved
bootstrap JSON, then downloads the standard outfield and goalkeeper WebP files
from the official Fantasy Premier League static asset host. Each generated
season folder includes a manifest with source URLs, checksums, byte sizes, and
the sync time.

These images and club marks are third-party assets. Before using or distributing
them, confirm that your use complies with the Premier League's current terms
and any applicable permissions.
